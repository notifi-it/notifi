Floating glass chrome

The nav and tab bar are Regular-variant Liquid Glass — translucent, blurred, refracting the feed behind them. In SwiftUI this is automatic: a NavigationStack + .searchable + a floating TabView adopt glass on iOS 26 with zero custom drawing.

Key filter bar

Appears only when you hold more than one key. Glass capsules; the selected one lifts with a red-tinted glass. It's a horizontal scroll of your keys — All · Grafana · Deploy Bot · Mail — filtering the feed by keyID.

Search, kept

The .searchable field lives in the glass header and scrolls away as you read, snapping back on pull-down. Searches title + message across the current key filter.

Long message → push

Rows clamp to two lines. Tapping pushes a detail screen where the full message, its link and image get real room — the glass nav slides with it.

Red, once

Red is the unread dot, the selected filter, the link button, and the tint on glass — nothing else. Everything structural is system grey so the accent always means “notifi”.

What this is

Option 1 you picked, dressed in the native glass system with a key-filter bar, Bricolage Grotesque, and notifi red. No custom components — every piece here is a stock SwiftUI control that adopts Liquid Glass by building on iOS 26.

One security note carried over: the filter shows key names (Grafana, Deploy Bot, Mail) which the device decrypts locally — the server never sends them in the clear. Say the word and I'll build this into the real app.
