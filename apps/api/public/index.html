How it works

Your phone holds the only key.

No account

There is nothing to sign up for. The app makes a keypair on first launch and that is your identity. Nothing to remember, nothing to leak.

Neither we nor Apple can read your messages

The app makes a keypair when you install it and registers the public half. That is the only half the server ever holds.

Every message is sealed to that key the moment it arrives, so what sits in the database is ciphertext, not text. Your phone holds the private half and is the only thing that can open it.

The push is sealed too. The alert Apple relays says only notifi; your phone unseals the real title and message on arrival, so it is never plaintext at Apple either.

What this does not hide: which device a send was for, when it happened, and roughly how big it was. It is the message body that is sealed.

Keys are per-script, and revocable

Make one key per thing that sends: CI, a backup job, a scraper. If a key leaks, revoke it and the rest keep working.

Send from anywhere

It is plain HTTP with no SDK, so anything that can make an HTTP request to it can send. Uses lists what that covers.

Reference

One endpoint.

GET or POST https://notifi.it/send

Authenticate with Authorization: Bearer <key>, or pass key as a parameter. Query parameters win over the body.

ParameterTypeNotes
key required string Your send key. Prefer the Authorization header, because query strings end up in logs.
title required string 1–200 characters. The only field that always shows.
message string Up to 16,000 characters. Long enough for a stack trace.
link URL Up to 2,048 characters. Opens when you tap the notification.
image URL Must be https. Up to 2,048 characters. PNG, JPEG or GIF, 5 MB max.

Rate limits

120 sends per hour per key. Over that you get 429 with a rate_limited code. Make more keys if you need more headroom.

Errors

400 invalid parameters · 401 unknown or revoked key · 429 rate limited. Every error returns a JSON body with a code and a human-readable message.

Message size

Up to 16,000 characters, so a full stack trace or a long log tail fits. The push preview is shortened to fit Apple's 4 KB budget; the app pulls the complete message when it syncs.

Download

iPhone or Mac.

One app, either platform. On the Mac it lives in the menu bar. A key belongs to one device, so you choose where a script lands, or make a key for each. Anything that can make an HTTP request can send to it, Linux boxes and Android phones included. You just receive on Apple hardware.
