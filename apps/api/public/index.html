How it works

No account, ever

There is nothing to sign up for. The app makes a keypair on first launch and that is your identity. Nothing to remember, nothing to leak.

The server cannot read your notifications

Message content is sealed to your device's public key the moment it arrives. Only your phone holds the private half, so the relay forwards ciphertext it has no way to open.

A relay, not a mailbox

Messages are held for seven days so a device that has been offline can catch up, then dropped. Your copies stay on your device for as long as you want them.

Keys are per-script, and revocable

Make one key per thing that sends — CI, a backup job, a scraper. If a key leaks, revoke it and the rest keep working.

Send from anywhere

It is plain HTTP with no SDK, so anything that can make a request can send: a shell script, a cron job, a Lambda, a GitHub Action, an ESP32.

Send

Eight ways to say the same thing.

GET or POST, JSON or form-encoded, key in the header or the query string. Pick whichever is least effort where you are.

send.sh

  -d "message=4.2 GB in 3m 11s" \
  -d "link=https://console.internal/backups"

Reference

One endpoint.

GET or POST https://notifi.it/send

Authenticate with Authorization: Bearer <key>, or pass key as a parameter. Query parameters win over the body.

ParameterTypeNotes
key required string Your send key. Prefer the Authorization header — query strings end up in logs.
title required string 1–200 characters. The only field that always shows.
message string Up to 2,000 characters.
link URL Up to 2,048 characters. Opens when you tap the notification.
image URL Must be https. Up to 2,048 characters. PNG, JPEG or GIF, 5 MB max.

Rate limits

120 sends per hour per key. Over that you get 429 with a rate_limited code. Make more keys if you need more headroom.

Errors

400 invalid parameters · 401 unknown or revoked key · 429 rate limited. Every error returns a JSON body with a code and a human-readable message.

Retention

Seven days on the server, then dropped. The copy on your device is yours to keep or delete.

Download

iPhone and Mac.

One app, both platforms. On the Mac it lives in the menu bar. Anything that can make an HTTP request can send to it — Linux boxes and Android phones included — you just receive on Apple hardware.
